# 安全边界

## 当前实现

- Argon2 密码哈希和 8 小时 JWT。
- 提交者、审核员、管理员三角色 RBAC。
- 审核员不能审核自己提交的任务。
- 上传文件限制 50 MiB，并校验扩展名与文件签名。
- SVG 使用 defusedxml，拒绝 DTD、外部实体和脚本。
- MinIO 对象键使用用户 UUID、SHA256 和任务 UUID，不直接使用用户文件名。
- 审计事件 append-only，并通过 SHA256 前序哈希链检测修改。
- 全局错误响应不返回堆栈，结构化日志不回传客户端。

## MVP 未包含

- 多租户与 PostgreSQL RLS
- OAuth2/OIDC、刷新令牌、密钥轮换
- 病毒扫描、DLP、敏感字段脱敏
- MinIO 服务端加密和 WORM 合规存储
- API 全局限流、WAF、TLS 终止
- 审核会签、或签、转审、申诉和 SLA 升级

生产化前必须增加上述能力，并替换默认密码、`SECRET_KEY`、MinIO 凭据和数据库密码。

## 文件解析威胁

解析工业文件属于不可信输入处理。当前 PDF/SVG/Gerber 解析不执行文档脚本，不进行渲染，也不访问文档内的外部 URL。仍建议生产环境：

1. 在独立低权限容器中运行 Worker。
2. 为 Worker 设置 CPU、内存和时间限制。
3. 接入 ClamAV 或企业病毒扫描服务。
4. 对解析库安全公告建立升级流程。
5. 将对象存储放在私有网络，不向公网暴露写权限。
